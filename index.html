Greeting

A personal publishing tool that uploads my finished videos to my own TikTok account.

What it does

  • Connects to a single TikTok account through TikTok's official OAuth flow.
  • Uploads video files I select from my own machine using TikTok's Content Posting API.
  • Shows the upload status and the returned post ID so I know the post succeeded.

What it does not do

  • It does not post to accounts I have not authorised.
  • It does not generate, scrape, or source content on its own.
  • It does not collect analytics, run ads, or share data with third parties.
